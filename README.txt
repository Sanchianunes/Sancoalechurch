CHURCH / PARISH WEBSITE

This is a starter website for displaying Mass times.

Files:
- index.html — the complete website

To customise later:
1. Open index.html in a browser.
2. Replace "Parish Name" with the church/parish name.
3. Replace the placeholder Mass times.
4. Add address, phone and email.
5. Replace church-placeholder.jpg with a church photo using the same filename.

The page is responsive and works on desktop and mobile.
