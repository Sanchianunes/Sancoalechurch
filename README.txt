# Sancoale Parish Website

Starter structure for the Sancoale Parish website.

## Files
- `index.html` — homepage and Mass timings
- `style.css` — all website styling
- `images/` — church photos and logo can be placed here
- `pages/` — future pages can be added here

## Adding the church photo
Place a photo named `church-placeholder.jpg` inside `images/`.
The homepage will automatically use it as the hero background.

## GitHub
Upload/replace `index.html`, upload `style.css`, and create the `images` and `pages` folders.
Commit the changes directly to the `main` branch.

## Current Mass information
Three churches are included:
- Sancoale Church
- Sanctuary
- Old Church

Some wording is intentionally left as placeholders for later parish details.
